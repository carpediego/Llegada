Cómo funciona de verdad

Importante: los navegadores no permiten usar el GPS con la app cerrada. Llegada vigila mientras está abierta (en primer plano o en una pestaña reciente) y puede mostrar notificaciones del sistema.

Qué sí hace

  • Detecta entrada y salida con un radio ajustable y un margen por la precisión del GPS.
  • Puede esperar X minutos antes de avisar y cancelar si sales del área.
  • Alarma con sonido, vibración, notificación y posponer.
  • Funciona sin conexión una vez cargada y guarda todo en tu dispositivo.

Qué no puede hacer

  • Despertarte con la app cerrada o el teléfono bloqueado durante horas.
  • Garantizar el GPS bajo techo, en sótanos o con el ahorro de batería extremo.
  • Enviarte avisos si el sistema operativo suspende el navegador.

Para una geocerca 24/7 de verdad hace falta una app nativa con permiso de ubicación en segundo plano. Este proyecto deja la base web lista para ese siguiente paso.

Tus recordatorios y coordenadas se guardan en este dispositivo. El mapa y las búsquedas de direcciones usan OpenStreetMap, así que el proveedor del mapa puede ver la zona que estás consultando. Llegada no tiene servidores propios ni cuentas.

Actualizaciones desde GitHub

  • La app consulta la versión publicada en GitHub Pages y el último release del repositorio.
  • Al instalar, descarga el paquete completo, comprueba el SHA-256 de cada archivo y lo activa al recargar.
  • También puedes descargar el .zip y guardarlo como copia o para publicarlo en otro sitio.
